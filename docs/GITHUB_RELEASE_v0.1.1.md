## 码盒 v0.1.1

面向 Vibe Coder 的本地灵感管理器。本版重点：**本地/云端双模式、工作区自动扫描、安装与桌面快捷方式**。

### ✨ 亮点

- **本地 / 云端仓库**：新建时可选；本地不自动 git init，云端支持 Git
- **工作区自动扫描**：启动后自动识别工作区内的项目
- **分类**：默认「个人 / 工作」及子分类
- **拖放文件夹**添加或更换本地路径
- **Codex / Cursor / Edge** 外部启动
- **向导式安装** + 桌面/开始菜单快捷方式

### 📥 安装

1. 下载下方 **Windows 安装包** `码盒 Setup 0.1.1.exe`
2. **双击 Setup** 完成安装（勿直接运行 win-unpacked）
3. 安装后桌面会出现「码盒」快捷方式
4. 需本机已安装 **Git**

默认工作区：`文档/码盒/repos`
