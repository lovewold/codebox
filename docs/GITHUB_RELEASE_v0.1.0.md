## 码盒 v0.1.0

面向 Vibe Coder 的本地灵感管理器：**克隆 GitHub 项目 → README/文件树阅读 → 内置终端执行 → Git 管理**，一站完成。

### ✨ 亮点

- 一键克隆与分类管理，三种视图浏览仓库
- 中文版 README 自动识别并优先展示（`README_CN.md` / `README-CN.md` 等）
- 内置 xterm 终端，按仓库复用会话，支持 Claude Code 等 CLI
- 文件树监听变更自动刷新
- Git 面板、GitHub 探索、AI 对话与 README 翻译

### 📥 安装

1. 下载下方 **Windows 安装包**（`.exe`）
2. 安装后启动「码盒」
3. 需本机已安装 **Git**

默认工作区：`文档/码盒/repos`

### ⚙️ 环境

- Windows 10 / 11（64 位）
- 首次使用 AI 功能请在设置中配置模型 API Key

### ⚠️ 说明

- 本版本为**测试版**，欢迎反馈 Issue
- 数据与 API Key 均仅存本地
